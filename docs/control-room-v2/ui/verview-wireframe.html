Category operating rules

Clear rules prevent categories, promotions and product types from becoming the same thing.

C
Category = permanent browsing structureExamples: Dresses, Tops and Accessories. A product can belong to more than one.
A
Automatic category = rule-based product setExamples: New arrivals or Sale. Membership updates when products meet the rule.
P
Promotion = temporary campaignA promotion can feature products from several categories without changing the catalogue hierarchy.

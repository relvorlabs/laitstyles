Design pressure tests

Built for the awkward cases.

The state selector changes the shared product model and rerenders every concept, so each card must solve the same production realities in its own way.

01 / STOCKExact-piece inventory

Low stock, one-of-one and sold-out states keep the product useful without fake urgency.

02 / FITVintage size truth

Label size, practical fit and exact measurements are separated instead of treated as interchangeable.

03 / CONTENTUnruly catalogue data

Long names, absent brands, unknown eras, missing metadata and no-discount prices stay stable.

04 / MEDIAOne or many images

Hover swap, explicit mobile cycling and a branded failure state prevent layout shifts.

05 / ACCESSKeyboard-ready actions

Visible focus, real buttons, native dialog semantics, Escape handling and live feedback.

06 / MOTIONAlive, not restless

Only transform and opacity animate; reduced-motion preferences remove nonessential movement.
